# PlataPay

Логотипы зарубежных AI-сервисов и других подписок, которые мы оплачиваем, и
конструктор вертикальных видео-риллс на их основе.

## Логотипы

99 PNG с прозрачным фоном лежат в корне репозитория — имя файла совпадает с
названием сервиса (`Spotify.PNG`, `Adobe Creative Cloud.PNG`, `GPT.PNG`).
Это единственный источник правды: и посты, и видео берут логотипы отсюда.

## Видео-риллс

`reels/` — конструктор роликов 1080×1920 для Reels, TikTok, Shorts и Клипов.
Сцены описываются в JSON, рендер собирает готовый MP4 с обложкой и текстом поста.

```bash
cd reels && npm install
npm run preview             # посмотреть в браузере
npm run render              # собрать все ролики в reels/out/
```

Подробности, список сцен и как добавить свой ролик — в [`reels/README.md`](reels/README.md).
