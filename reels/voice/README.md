# Записи диктора

Сюда кладутся готовые аудиофайлы, если реплики озвучивает человек, а не синтез:

```
reels/voice/<проект>/01.wav
reels/voice/<проект>/02.wav
...
```

Номер = порядковый номер реплики в ролике. Эта же команда кладёт рядом
`script.txt` — готовый лист для записи: что именно читать под каким номером и
сколько секунд на реплику есть:

```bash
npm run voice -- --project=<проект> --check
```

Это путь `--provider=file`. Если голос синтезируется (HeyGen, ElevenLabs,
OpenAI), эта папка не нужна — реплики берутся из проекта.

Подходят `wav`, `mp3`, `m4a`, `aac`, `ogg` — пайплайн сам приведёт к нужному
формату, выровняет громкость до −16 LUFS и расставит реплики по таймингам сцен.
Паузы между фразами вырезать не нужно: файл должен содержать только саму реплику.
